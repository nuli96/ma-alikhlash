   - Grafik Batang Rombel (Distribusi per Kelas 1, 2, dan 3) dengan efek garis animasi *shimmer*.

3. **Portal Pendidik & Kehadiran Guru**:
   - Gerbang keamanan autentikasi kode masuk guru.

## 🚀 Panduan Cara Menjalankan Aplikasi

Aplikasi ini dibangun menggunakan arsitektur web modern murni (*Vanilla JavaScript, HTML5, CSS3*) tanpa dependensi server yang rumit, sehingga dapat dijalankan baik secara **offline** maupun di-hosting secara **online**.

### A. Membuka di Komputer / Laptop (Mode Lokal)
1. Unduh atau ekstrak seluruh folder proyek `PROJECT WEBSITE SEKOLAH` ke laptop/komputer Anda.
2. Klik dua kali pada berkas **`index.html`** untuk langsung membukanya di peramban web (*Google Chrome, Microsoft Edge, Mozilla Firefox, Opera*).
3. Aplikasi akan langsung berjalan penuh dengan data lokal madrasah.

### B. Menjalankan Melalui Local Web Server (Direkomendasikan)
Jika Anda menggunakan ekstensi seperti *Live Server* di VS Code:
1. Buka folder proyek di editor kode.
2. Klik kanan pada berkas `index.html` lalu pilih **Open with Live Server**.
3. Akses melalui alamat: `http://127.0.0.1:5500/`

## 📖 Panduan Penggunaan Sistem

### 1. Alur Presensi Mandiri & Jurnal KBM (Untuk Dewan Guru)
1. Buka tab **Absensi Guru** pada menu navigasi.
2. Pada modal keamanan, pilih nama Anda dan masukkan **Kode Masuk Guru** (misal: `TITA123`, `MIMI123`, `NULI123`, dst).
3. **Presensi Mandiri**:
   - Buka sub-tab *1. Presensi Mandiri (Selfie)*.
   - Klik *Buka Kamera* lalu ambil foto kehadiran atau unggah foto bukti kegiatan.
   - Pilih jenis presensi (Pagi/Siang/Dinas Luar) dan klik *Simpan Presensi Kehadiran*.
4. **Catat Aktivitas KBM**:
   - Buka sub-tab *2. Catat Aktivitas KBM*.
   - Pilih kelas rombel, masukkan jam mengajar, mata pelajaran, dan ringkasan materi/modul ajar.
   - Klik *Simpan Jurnal KBM*.

### 2. Alur Input Kehadiran Siswa (Untuk Wali Kelas / Guru Piket)
1. Buka tab **Kehadiran Siswa**.
2. **Langkah 1**: Tentukan *Tanggal Presensi* dan pilih *Guru Pengisi Absensi*.
3. **Langkah 2**: Klik tab rombel yang dituju (*Kelas 1*, *Kelas 2*, atau *Kelas 3*).
4. **Langkah 3**: Tentukan status setiap siswa dengan mengklik tombol status:
   - **H**: Hadir
   - **S**: Sakit
   - **I**: Izin
   - **A**: Alpa
   *(Tersedia tombol "Tandai Semua Hadir" untuk mempercepat pengisian jika seluruh siswa masuk).*
5. **Langkah 4**: Klik tombol **💾 Simpan Data Presensi** di bagian bawah.
6. Data langsung tersimpan ke riwayat database dan tersinkron otomatis ke Google Sheets.

### 3. Mengelola & Mengoreksi Riwayat Presensi Siswa
1. Pada tab **Kehadiran Siswa**, klik sub-tab **2. Database & Riwayat**.
2. Anda dapat memfilter riwayat berdasarkan kelas atau tanggal.
3. Untuk memperbaiki catatan salah: klik tombol **Buka & Edit**. Sistem akan memuat sesi tersebut kembali ke layar input untuk direvisi.
4. Untuk mengunduh rekap lembar Excel resmi per tanggal: klik tombol **Excel**.
5. Untuk menghapus sesi: klik tombol tanda silang (**&times;**). Sesi yang dihapus di web akan **otomatis membersihkan baris di Google Sheets**!

### 4. Mengakses Panel Administrator / Operator Kurikulum
1. Klik tombol **Admin / Operator** di bagian navigasi.
2. Masukkan kredensial resmi operator:
   - **Username**: `admin`
   - **Password**: `nmcode`
3. Di dalam Panel Operator Anda dapat:
   - Mengoreksi penulisan nama guru, NIP, mapel, dan mengatur kode masuk guru.
   - Mengoreksi data siswa (nama, NISN, kelas, gender) atau menambah peserta didik baru.
   - Mengubah logo madrasah dan identitas kelembagaan.
   - Melakukan sinkronisasi dua arah ke Google Sheets (*Kirim Semua Data* atau *Tarik Data Terkini*).
   - Mengunduh cadangan offline database dalam format `.JSON`.
